# SpaceCadetPinball

## Summary

Reverse engineering of `3D Pinball for Windows - Space Cadet`, a game bundled with Windows.

## How to play

### Native DOS / Tandy and VGA prototype (this fork)

A standalone 8086/V20 real-mode Space Cadet prototype is in
[Platform/dos](Platform/dos/README.md), with imported Windows
`PINBALL.DAT` resources, fixed-point physics, and **both standard VGA
mode 13h and Tandy/PCjr mode 09h**. It automatically selects VGA when
supported, otherwise Tandy, with `/vga` and `/tandy` overrides. Both
use identical 320×200, 16-color source artwork and optional offline
3D shading, with automated DOS gameplay and video-parity tests.
Its core is **playable but not a feature-complete copy**
of the original Space Cadet. See the
[**DOS feature inventory and missing implementations**](Platform/dos/FEATURE_STATUS.md)
and [hardware/CI validation notes](Platform/dos/VALIDATION.md).
The CI artifact includes the matching game and table data.

**Source-aligned DOS architecture:** Open Watcom compiles `table.c`
separately for resource loading and indexing. Gameplay in `game.c`
and DOS platform/rendering code in `main.c` use ordered, named `.inc`
implementation fragments for collisions, flippers, plunger, kickbacks,
nudges, recovery, input, video, HUD and audio. They remain in their
original translation units to avoid extra calls in the V20 hot path.
These `.inc` files are **not standalone objects**. Read the
[DOS architecture/build guide](Platform/dos/README.md#source-aligned-architecture),
[original-to-DOS source map](Platform/dos/SOURCE_MAP.md), and
[fidelity exception register](Platform/dos/FIDELITY.md).
A source mapping is not a claim of complete gameplay equivalence.

The owner has tested earlier revisions on a real Tandy 1000 EX/V20 and
reported several physics/collision issues; automated regressions were added
for the subsequent fixes, but **the latest build's real-hardware
performance and final playability remain unverified**. The new
standard VGA path passes DOSBox-X testing, including a complete 64000-pixel
frame comparison with the Tandy renderer, but has not yet been tested
on physical VGA hardware.

### Desktop version

Place compiled executable into a folder containing original game resources (not included).\
Supports data files from Windows and Full Tilt versions of the game.

## Tools used

`Ghidra`, `Ida`, `Visual Studio`

## What was done

* All structures were populated, globals and locals named.
* All subs were decompiled, C pseudo code was converted to compilable C++. Loose (namespace?) subs were assigned to classes.

## Compiling

The **desktop** version uses `C++11` and depends on `SDL2` libraries.
The **native DOS** version is an independent 16-bit C89/Open Watcom 2
target. Build it with `python Platform/dos/build.py` and follow the
[DOS build and asset instructions](Platform/dos/README.md#build-and-play).

### On Windows

Download and unpack devel packages for `SDL2` and `SDL2_mixer`.\
Set paths to them in `CMakeLists.txt`, see suggested placement in `/Libs`.\
Compile with Visual Studio; tested with 2019.

### On Linux

Install devel packages for `SDL2` and `SDL2_mixer`.\
Compile with CMake; tested with GCC 10, Clang 11.\
To cross-compile for Windows, install a 64-bit version of mingw and its `SDL2` and `SDL2_mixer` distributions, then use the `mingwcc.cmake` toolchain.

[![Packaging status](https://repology.org/badge/tiny-repos/spacecadetpinball.svg)](https://repology.org/project/spacecadetpinball/versions) 

Some distributions provide a package in their repository. You can use those for easier dependency management and updates.

This project is available as Flatpak on [Flathub](https://flathub.org/apps/details/com.github.k4zmu2a.spacecadetpinball).

### On macOS

Install XCode (or at least Xcode Command Line Tools with `xcode-select --install`) and CMake.

**HomeBrew**

You can easily install the build artifact by using `brew`.

```sh
brew tap draftbrew/tap
brew install --no-quarantine space-cadet-pinball
```

Be aware that the flag `--no-quarantime` will disable macOS's Gatekeeper during installation.

**Manual compilation:**

* **Homebrew**: Install the `SDL2`, `SDL2_mixer` homebrew packages.
* **MacPorts**: Install the `libSDL2`, `libSDL2_mixer` macports packages.

Compile with CMake. Ensure that `CMAKE_OSX_ARCHITECTURES` variable is set for either `x86_64` Apple Intel or `arm64` for Apple Silicon.

Tested with: macOS Big Sur (Intel) with Xcode 13 & macOS Montery Beta (Apple Silicon) with Xcode 13.

**Automated compilation:**

Run the `build-mac-app.sh` script from the root of the repository. The app will be available in a DMG file named `SpaceCadetPinball-<version>-mac.dmg`.

Tested with: macOS Ventura (Apple Silicon) with Xcode Command Line Tools 14 & macOS Big Sur on GitHub Runner (Intel) with XCode 13.
